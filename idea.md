# Ідея: мобільний додаток для колекціонерів іграшок з Kinder

## Опис

Мобільний додаток для колекціонерів іграшок з шоколадних яєць Kinder Surprise (Kinder Joy тощо). Додаток допомагає вести особисту колекцію, відстежувати серії та рідкісні екземпляри, а також обмінюватись або продавати дублікати з іншими колекціонерами.

## Основні функції

- **Каталог серій** — база даних усіх випущених серій та фігурок Kinder з фото, роком випуску, країною та рівнем рідкісності.
- **Моя колекція** — можливість позначати, які іграшки вже є у користувача, з фото власного екземпляра та станом (нова / б/у).
- **Список бажань (wishlist)** — фігурки, яких не вистачає для завершення серії.
- **Обмін і продаж** — модуль для зв'язку з іншими колекціонерами: пропозиції обміну дублікатів, оголошення про продаж.
- **Сповіщення** — про нові серії, знайдені збіги для обміну, зміни цін.
- **Прогрес по серії** — візуальний індикатор скільки фігурок із серії вже зібрано.
- **Спільнота** — профілі колекціонерів, рейтинг/відгуки після обміну, форум або стрічка.

## Потенційна монетизація

- Freemium: базовий функціонал безкоштовний, преміум — розширена аналітика колекції, без реклами, пріоритет у пошуку для обміну.
- Комісія з угод обміну/продажу.
- Партнерство з магазинами колекційних товарів.

## Технічні нотатки

- Потрібна велика довідкова база даних фігурок Kinder (можливо, краудсорсинг від спільноти з модерацією).
- Кросплатформенність (iOS/Android) — варто розглянути React Native або Flutter.
- Функція розпізнавання фігурки за фото (OCR/image recognition) як опційна фіча для швидкого додавання в колекцію.

## Наступні кроки

- Дослідити наявні конкуруючі додатки та спільноти колекціонерів.
- Оцінити юридичні аспекти використання бренду Kinder (торгова марка Ferrero) — можливо, потрібна нейтральна назва додатку.
- Визначити MVP-скоуп: каталог + моя колекція + wishlist, без обміну на першому етапі.
